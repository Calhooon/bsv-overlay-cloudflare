## Findings (all NOTE)

### NOTE-1 — the second-set gate (`spentConfirmed=1`) is narrower than the owed money bar
`d1_discovery.rs:2171` / `SPENT_UNCLASSIFIED_INDEX_PREDICATE:2183`. The owed claimable gate
`settle_spend_confirmed` (`owed.rs:1258`) is `at_height || spentConfirmed || checked_tracker_mined`;
the results view serves a verdict under `is_confirmed_landing_with_proof`
(`logic.rs:1956`: `spentConfirmed OR proof_verified OR (seen AND final)`). A covenant settle that
becomes provable (a `proof_verified` BEEF, or a checked-tracker-mined word) while `spentConfirmed=0`
has its verdict left unlatched, so D1 shows `payout … claimable` and the actor shows `unbound`.
This is the SAFE direction (the actor's served set ⊆ D1's, NOTE-4) and, for the ordinary case, one
confirmation-pass tick (the chase latches when it sets `spentConfirmed`, `proof_fetcher.rs:3328`).
A persisting edge remains (a stored-verified proof chaintracks will not re-verify fresh, or a
tracker word with no `pot_beefs` proof): the actor keeps withholding, never over-serving. The
actor also cannot compute `at_height` from the BEEF bump (empty-blob mirror), so the FULL heal of
this class is item 2(a)/Calgooon/bsv-low#997 (serve the spender BEEF from the mirror), which the PR
explicitly defers. The fix delivers its stated contract — the CONFIRMED beta family-D population
(all `spentConfirmed=1`) — fully. The fold chose the flag gate over aligning it because the aligned
gate forces a full walk of the 8,097-row partial index (measured). **Agree as a residual; I
considered LOW and settled on NOTE: no money hole, no regression (the whole class was `unbound`
before the PR), contract delivered, deeper fix filed.** The fold could add one sentence naming the
owed bar's `checked_tracker_mined` arm (not only the results-view bar) as part of this residual.

### NOTE-2 — a held-bytes row matching no mandated exit is a permanent candidate
`proof_fetcher.rs:3798` loop. A spent/confirmed/decoded covenant row whose held spender bytes match
no mandated exit is never latched, stays in the partial index, and re-logs each tick it is sampled.
Both judges answer `unbound`, so no divergence; the cost is bounded (16/tick, no courier). The log
line ("match no mandated exit") also fires on conservation/outpoint failures — minor imprecision.
Unreachable for a real covenant spend. Left as is by the fold; concur.

### NOTE-3 — no budget-tier ceiling covers the backfill's second scan; native bound instead
`ORDER BY RANDOM() LIMIT 16` over the partial index reads the whole confirmed-unclassified backlog
each tick (`d1_hot_bounds.rs` `fix986_the_unclassified_scan_reads_its_partial_index_and_no_fleet_table`,
176 VM steps on the fleet = alone, no fleet-table scan). The scan adds no courier calls. The route
tiers do not reach this path (it runs only from the scheduled tick / `/admin/complete-proofs`), so a
native bound is the right instrument. Concur.

### NOTE-4 — the fix is monotone-safe (favourable)
The actor reads only the stored verdict; D1 reads the stored verdict then its BEEF fallback. So the
actor's served set is a subset of D1's — the fix can only make the actor catch up to D1, never
over-serve a press. This is why NOTE-1's direction is safe.
